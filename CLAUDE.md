# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

"Aporte" (formerly "Minha Carteira"; repo and localStorage keys keep the old name) is a personal investment-portfolio PWA (pt-BR UI, BRL/USD, Brazilian + US holdings). It is a static site hosted on GitHub Pages (`.nojekyll`); the repo holds only code — user data lives in the browser (localStorage) and in the private repo described under Cloud sync.

There is no build system, package manager, test suite or linter. To develop, edit the files and open `index.html` in a browser (or serve the directory with any static server, e.g. `python3 -m http.server`).

## Architecture

Everything is in a single `index.html` (~1200 lines: inline CSS, markup, then one IIFE `<script>`). `manifest.webmanifest`, `icon.svg` and `sw.js` (service worker: network-first for the app's own files, cache fallback so it opens offline; never touches API calls) make it installable. Code is written in dense ES5 style (`var`, `function`, no modules) — keep that style when editing.

Key pieces inside the script:

- **State `S`** (persisted to `localStorage` key `minha-carteira-v1` via `save()`): `trades`, `cambio`, `quotes` (auto price cache), `fx`, `keys` (Finnhub, brapi and GitHub tokens), `pend` (cloud ops queue), `mclose`, `divFrom`. A separate key `minha-carteira-v1-fxh` caches the USD-BRL daily series (refetched after 6h).
- **Market data `MK`**: `ingestFx` loads the FX series; `getQuote(tk)` reads `S.quotes`; `fxOn(date)`/`fxToday()` resolve exchange rates.
- **`compute()`**: the core calculation. Sorts trades by date, builds per-ticker positions (qty, cost basis, realized P/L, dividends via `side==='div'`), converts US trades with each trade's `fx`, builds cash-flow list for `xirr()`.
- **Tabs**: bottom nav `resumo` (Início), `ativos` (Carteira, sub-views `pos`/`evo`/`apo`/`perf`/`ext` (Extrato, hashes `#extrato`/`#lancamentos`) via `data-sub2`/`CARV`, hashes `#evolucao`/`#aporte`/`#desempenho`; `perf` = `renderPerf`/`perfHtml`: carteira contra o mercado e o CDI), `proventos` (sub-views `DVV` 'mes'/'rec' via `#dvseg`; `recHtml` lists every announced provento by payment year, 'a definir' last), `mercado` (`renderMkt`/`loadMkt`, sub-tabs `#mkseg` `data-mkv` → `MKV` 'min'/'idx'/'ana' saved in `minha-carteira-v1-mkv`: 'min' = `mineHtml` (holdings with price, day %, P/L·P/VP·DY) + watchlist; 'ana' = `anaHtml` (ranking presets `SCRS`/`SCR` over `MD.d.fund`, liquidez ≥ R$ 1 mi, and 'Comparar duas ações' form `#cmpf` → `CMP`); 'idx' = índices; search bar `#mk-q` (`mkSearch`: catalog indices + any ticker to open/acompanhar) and user-chosen índices from the `IDX` catalog (brapi ^BVSP/XFIX11/SMAL11/DIVO11, Finnhub SPY/QQQ/DIA/ACWI/EEM/GLD, AwesomeAPI moedas/cripto, BCB CDI and IPCA 12m), selection `S.idxSel` synced as cfg op 'idx', "Editar" shows ✕ on cards; and the watchlist `S.watch`, synced as cfg op 'watch', cached `minha-carteira-v1-mkt`), `mais` (sub-views `cambio`/`imposto`/`ajustes` via `data-sub` and `MAISV`); `showTab` accepts the old hashes.
- **Temas**: `atual` = "Azul" (default, the dark navy palette on bare :root; the user saw this before via dark mode, no data-theme), `branco` and `preto` via `data-theme` on <html>, chosen in Ajustes (`#temas`, `setTema`), stored per device in `minha-carteira-v1-tema` and applied by an inline head script before paint. No automatic dark mode.
- **Gráficos**: SVG helpers `spark(rows)` (hero, from `evoData()`), `distHtml(R)` (Distribuição on Início: swipeable pages `#dcar`/`DCI` — Por tipo, Todos os ativos, Ações, ETFs Intern., Renda fixa when present — big donuts; tapping a slice `.dsl` shows `#dtip` with name, % and R$ and dims the others), `vsBars` (vs mercado/CDI); waterfall bars in "De onde vem"; Evolução is an area chart plus monthly rendimento bars. Long explanatory notes carry class `note exp` and are wrapped by `foldNotes()` (MutationObserver) into a collapsed "Entenda" `details.info`.
- **Início vs Desempenho** (user rule: never mix câmbio/vendas into the Início numbers): hero is a swipeable card row (`#hcards`, scroll-snap, dots `HCI`, like Investidor10): order Patrimônio total (% vs valor investido at today's dollar), then Variação de hoje / Último pregão, then Valorização (user's order) (price only, VT × today's dollar for both closes, split Brasil/VT). Valorização = `valoriz(R)` (price variation of holdings with VT at today's dollar + RF rendimento + proventos received; % over cost at today's dollar). Início now holds only the hero cards, then Distribuição, then Metas (user wants it uncluttered); "Carteira hoje" (`hojeHtml`) and "Quanto você investiu" (`investHtml`) moved to the end of Desempenho. The full breakdown (preço, dólar, vendas, proventos, taxas, lucro total, simples, XIRR) lives at the top of `perfHtml` (Carteira → Desempenho); its preço line uses `valoriz().pv` and dólar is the remainder so the sum still equals `tot.gain`.
- **Ativos (Carteira → Ativos)**: `atvTable(R)` = Investidor10-style table (logo from icons.brapi.dev / financialmodelingprep image-stock with initials fallback, qty, Total % and Dia % pills via `vpill` → tap shows the R$ value in a balloon, tap the ticker cell (sticky first column) opens `stkOpen`; the table scrolls sideways (`.atsc`) with extra columns Total R$, Preço médio, Preço atual, Valor); filter `ATF` all/BR/US, sort `ASRT` by header tap. Price-only basis (VT × today's dollar). Renda fixa and Encerradas stay as groups below.
- **Página da ação** (`#stk` sheet, `stkOpen(tk)` from any `[data-stk]`): BR via brapi: main quote with the largest range the plan allows (falls back 5y→1y→6mo→3mo→1mo→none), then separate optional calls for modules and dividends=true; what the plan refuses is remembered in `minha-carteira-v1-brcap`; when the plan caps the range (free = 3 months), the chart comes from Alpha Vantage `TK.SAO` (avHist) instead; US via Finnhub quote/profile2/metric + Alpha Vantage daily/weekly history (cached a day, 25 calls/day limit). Line chart with touch tooltip and the user's preço médio line; indicators read defensively with `pickNum`.
- **Robô diário** (data repo `.github/workflows/mercado.yml` + `scripts/mercado.py`, GitHub Actions, free): runs 06:17 and 18:40 BRT and on every push of carteira.json; writes `mercado.json` (v 2) = `idx` histories for the Mercado index catalog (Yahoo real indices like ^BVSP/^GSPC/^IXIC/^DJI/GC=F, FX pairs, BTC/ETH-USD × BRL=X, IFIX.SA→XFIX11.SA fallback; CDI série 4389 rate + 12m from série 12; IPCA série 433 12m accumulated) shown by `idxOpen`/`idxRender` when an index card is tapped (when the robot symbol differs from the live proxy, the page uses the robot's last close and only the day % from the proxy) + Fundamentus indicators for all B3 stocks (`fund` {cols,d}) + Yahoo 5y weekly/1y daily closes and dividend history for held + watched tickers (`hist`). The app reads it via the contents API (raw, ETag) in `loadMD` (cached `minha-carteira-v1-md`); `mdStk` builds the stock page instantly from it (live price from S.quotes/MKT.q), falling back to the API path only when a ticker isn't there yet. `fundOf(tk)` treats Fundamentus 0 as missing (except DY).
- **Assistente de IA**: removed at the user's request (Gemini from the browser never answered on his phone). Startup code deletes the old key `S.keys.gm` and its caches. Don't re-add unless asked.
- **Balões**: `bal(text, inner)` makes a small tap-to-show explanation (`#balpop`, hides on any other tap or scroll). Used for unclear labels on Início and for the EUA line (shows US$ result, balloon has the reais conversion). Prefer balloons over more visible text.
- **Toque nos gráficos**: a `.tipc` wrapper with `data-tip` JSON `{n:slots, pts:[{i,t,r:[[color,label,value,cls]]}]}` (built by `tipAttr`) gets a touch/drag tooltip (`tipShow`/`tipHide`, document pointer events; tap elsewhere hides). Used in Evolução and Proventos mês a mês; donut slices show their % in the center on tap.
- **Rendering**: `render()` calls `renderSummary`, `renderPositions`, `renderTrades`, `renderBanner`, `renderFx` — all rebuild HTML strings (escape with `esc()`); tabs switch via `showTab`. Form handling is in `syncForm`.
- **Live refresh `doRefresh()`**: every 5 min fetches USD-BRL and US quotes; BR quotes only every 15 min (`RF.lastBr`, brapi monthly limit; a manual refresh fetches all). Fetches USD-BRL from AwesomeAPI, US quotes from Finnhub (needs user key) and BR quotes from brapi.dev (needs user token, sequential with retry; skipped while B3 is closed once the closing price is cached, see `mktOpen`/`needQuote`). Uses `getJSON` with an 8s abort timeout.
- **Pregão**: `b3Hol(ymd)` knows B3 holidays (fixed dates + Carnaval/Sexta-feira Santa/Corpus Christi from Easter); `bDay`, `mktOpen`, `lastClose` and `dayLbl` skip them.
- **Dividendos dos EUA**: `loadDivsUS()` (every 12h, key `S.keys.av`) calls Alpha Vantage `function=DIVIDENDS` per US ticker; data-com = ex-date − 1 day; value = qty × amount minus 30% US withholding (`bruto`/`irExt` in USD). Future payments go to `DU.up` (cached `minha-carteira-v1-divus`, `val` in BRL at today's dollar, `us:1`); paid ones on/after `S.divFrom` are auto-added as `div` trades (dedupe ±7 days). `mergeUp()` joins `DV.br` (brapi) and `DU.up` into `DV.up`.
- **Taxas**: BR buy/sell trades may carry `taxa` (fees from the Nubank note, R$, split across the note's trades by value). `ePx(t)` gives the effective price (buy: price + taxa/qty; sell: price − taxa/qty). The user wants fees kept OUT of the preço médio (matches Nubank): compute() keeps cost basis/realized at the plain price, uses ePx only for cash/contrib/flows, and reports `tot.fees` as its own line (subtracted from `tot.gain`). ePx is used fully in irData (gain only; the R$ 20 mil limit uses gross sales) and bensEm (Receita rules), and for cash in evoData, benchSeg, cdiBench and the Extrato totals.
- **Renda fixa**: trades with `side:'rf'` (aplicação: `price` = valor aplicado, `pct` = % do CDI, `isento`, `venc`) and `side:'rfout'` (resgate, `ref` = aplicação id, `price` = valor recebido), `market:'RF'`. `rfCalc()` compounds the BCB SGS série 12 daily CDI (`loadCDI`, cached in `minha-carteira-v1-cdi`) from the aplicação date up to (not including) today/resgate, then applies IOF (<30 dias) and IR regressivo on (rendimento − IOF).
- **Cloud sync**: `ghSync()` reads/writes `carteira.json` in the private repo `THIAGOATAIDE2003/minha-carteira-dados` via the GitHub contents API with the user's fine-grained token (`S.keys.gh`); local edits queue in `S.pend` (add/del ops) and are replayed on the latest remote on conflict.
- **Evolução** (Investidor10 style): `renderEvo` draws stacked bars per month: Valor aplicado (`--ev1`, cost of holdings at that month's dollar) + Ganho de capital (`--ev2`, value − cost; negative drawn below zero), y axis in a separate SVG, touch tooltip, table in a collapsed details. Filter sheet (`#evsheet`, `EVF` {p:'all'|'12'|'24'|'60'|'120', t:'all'|'BR'|'US'|'RF'}, saved in `minha-carteira-v1-evof`). `evoData()` rows carry `seg` {BR,US,RF:{v,c}}. `evoData()` replays trades up to each month end; prices come from brapi daily history (`loadHist`, cached in `minha-carteira-v1-hist`) or `fechamentos` in the cloud file (month closes; the app records the current month's auto quotes as `px` ops, once a day), falling back to average cost (marked *).
- **Aporte**: `S.alvos` `{classes:{BR,US,RF}, br:{ticker:%}}` synced as a `cfg` op (`applyCfg`); `splitNeed` sends new money to what is furthest below target, never sells.
- **Mercado**: `loadBench` caches BOVA11/IVVB11 daily closes (`minha-carteira-v1-bench`); `benchSeg(mk,etf)` replays each segment's buys/sells into the ETF on the same dates and compares gains (portfolio side includes dividends).
- **Metas**: `S.metas` `{pat:{valor,data}, renda:{valor}}` synced as a `cfg` op; `metasHtml` (Início) shows progress, the monthly contribution needed at the CDI rate, and time to goal at the recent contribution pace.
- **Imposto**: `irData()` replays BR buys/sells (average cost) per month: ações isentas até R$ 20 mil de vendas no mês, senão 15%; FIIs (`FIIS` list) 20%; prejuízo carried per category. `bensEm(date)` gives Bens e Direitos cost at 31/12; proventos split by `tipo` (JCP/Dividendo) and exterior (`bruto`, `irExt`).

Keep user data and API keys out of the repo; the app must keep working offline from `localStorage` when network calls fail.

# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project

"Aporte" (formerly "Minha Carteira"; repo and localStorage keys keep the old name) is a personal investment-portfolio PWA (pt-BR UI, BRL/USD, Brazilian + US holdings). It is a static site hosted on GitHub Pages (`.nojekyll`); the repo holds only code — user data lives in the browser (localStorage) and in the private repo described under Cloud sync.

There is no build system, package manager, test suite or linter. To develop, edit the files and open `index.html` in a browser (or serve the directory with any static server, e.g. `python3 -m http.server`).

## Architecture

Everything is in a single `index.html` (~1200 lines: inline CSS, markup, then one IIFE `<script>`). `manifest.webmanifest`, `icon.svg` and `sw.js` (service worker: network-first for the app's own files, cache fallback so it opens offline; never touches API calls) make it installable. Code is written in dense ES5 style (`var`, `function`, no modules) — keep that style when editing.

Key pieces inside the script:

- **State `S`** (persisted to `localStorage` key `minha-carteira-v1` via `save()`): `trades`, `cambio`, `quotes` (auto price cache), `fx`, `keys` (Finnhub, brapi and GitHub tokens), `pend` (cloud ops queue), `mclose`, `divFrom`. A separate key `minha-carteira-v1-fxh` caches the USD-BRL daily series (refetched after 6h).
- **Market data `MK`**: `ingestFx` loads the FX series; `getQuote(tk)` reads `S.quotes`; `fxOn(date)`/`fxToday()` resolve exchange rates.
- **`compute()`**: the core calculation. Sorts trades by date, builds per-ticker positions (qty, cost basis, realized P/L, dividends via `side==='div'`), converts US trades with each trade's `fx`, builds cash-flow list for `xirr()`.
- **Tabs**: bottom nav `resumo` (Início), `ativos` (Carteira, sub-views `pos`/`evo`/`apo`/`perf`/`ext` (Extrato, hashes `#extrato`/`#lancamentos`) via `data-sub2`/`CARV`, hashes `#evolucao`/`#aporte`/`#desempenho`/`#risco`; `perf` = `renderPerf`/`perfHtml`: carteira contra o mercado e o CDI), `proventos` (Investidor10 style, `renderDivPanel`/`pvRedraw`: `pvItems()` unifies received `div` trades and announced `DV.up` with status rec/up/def; swipe cards `#pcards`/`PCI` (total, 12 meses, este mês, provisionados, média mensal with metas.renda ring); `pvEvo` stacked bars recebidos + a receber (up to 6 months ahead) with sheet `#pvsheet` (período, mensal/anual, tipo, ativo); `pvAtivos` donut + bars (selects `data-pvs`); `pvList` 'Meus proventos' with period sheet `#pvlsheet` (incl. month picker), filter sheet `#pvfsheet` and details table `#pvdsheet`; settings in `PV`, saved in `minha-carteira-v1-pv`; open sheet kept in `PVS` across re-renders; then `divPorAtivo`), `mercado` (`renderMkt`/`loadMkt`, sub-tabs `#mkseg` `data-mkv` → `MKV` 'min'/'idx'/'ana' saved in `minha-carteira-v1-mkv`: 'min' = `mineHtml` (holdings with price, day %, P/L·P/VP·DY) + watchlist; 'ana' = `anaHtml` (ranking presets `SCRS`/`SCR` over `MD.d.fund`, liquidez ≥ R$ 1 mi, and 'Comparar duas ações' form `#cmpf` → `CMP`); 'idx' = índices; search bar `#mk-q` (`mkSearch`: catalog indices + any ticker to open/acompanhar) and user-chosen índices from the `IDX` catalog (brapi ^BVSP/XFIX11/SMAL11/DIVO11, Finnhub SPY/QQQ/DIA/ACWI/EEM/GLD, AwesomeAPI moedas/cripto, BCB Selic meta série 432, CDI and IPCA 12m; robot `idx.selic` history, future-dated entries dropped), selection `S.idxSel` synced as cfg op 'idx', "Editar" shows ✕ on cards; and the watchlist `S.watch`, synced as cfg op 'watch', cached `minha-carteira-v1-mkt`), `mais` (sub-views `cambio`/`imposto`/`ajustes` via `data-sub` and `MAISV`); `showTab` accepts the old hashes.
- **Temas**: `atual` = "Azul" (default, the dark navy palette on bare :root; the user saw this before via dark mode, no data-theme), `branco` and `preto` via `data-theme` on <html>, chosen in Ajustes (`#temas`, `setTema`), stored per device in `minha-carteira-v1-tema` and applied by an inline head script before paint. No automatic dark mode.
- **Gráficos**: SVG helpers `spark(rows)` (hero, from `evoData()`), `distHtml(R)` (Distribuição on Início: swipeable pages `#dcar`/`DCI` — Por tipo, Todos os ativos, Ações, ETFs Intern., Renda fixa when present — big donuts; tapping a slice `.dsl` shows `#dtip` with name, % and R$ and dims the others), `vsBars` (vs mercado/CDI); waterfall bars in "De onde vem"; Evolução is an area chart plus monthly rendimento bars. Long explanatory notes carry class `note exp` and are wrapped by `foldNotes()` (MutationObserver) into a collapsed "Entenda" `details.info`.
- **Início vs Desempenho** (user rule: never mix câmbio/vendas into the Início numbers): hero is a swipeable card row (`#hcards`, scroll-snap, dots `HCI`, like Investidor10): order Patrimônio total (% vs valor investido at today's dollar), then Variação de hoje / Último pregão, then Valorização (user's order) (price only, VT × today's dollar for both closes, split Brasil/VT). Valorização = `valoriz(R)` (price variation of holdings with VT at today's dollar + RF rendimento + proventos received; % over cost at today's dollar). Início now holds only the hero cards, then Distribuição, then Metas (user wants it uncluttered); "Carteira hoje" (`hojeHtml`) and "Quanto você investiu" (`investHtml`) moved to the end of Desempenho. The full breakdown (preço, dólar, vendas, proventos, taxas, lucro total, simples, XIRR) lives at the top of `perfHtml` (Carteira → Desempenho); its preço line uses `valoriz().pv` and dólar is the remainder so the sum still equals `tot.gain`.
- **Ativos (Carteira → Ativos)**: `atvTable(R)` = Investidor10-style table (logo from icons.brapi.dev / financialmodelingprep image-stock with initials fallback, qty, Total % and Dia % pills via `vpill` → tap shows the R$ value in a balloon, tap the ticker cell (sticky first column) opens `stkOpen`; the table scrolls sideways (`.atsc`) with extra columns Total R$, Preço médio, Preço atual, Valor); filter `ATF` all/BR/US, sort `ASRT` by header tap. Price-only basis (VT × today's dollar). Renda fixa and Encerradas stay as groups below.
- **Página da ação** (`#stk` sheet, `stkOpen(tk)` from any `[data-stk]`): BR via brapi: main quote with the largest range the plan allows (falls back 5y→1y→6mo→3mo→1mo→none), then separate optional calls for modules and dividends=true; what the plan refuses is remembered in `minha-carteira-v1-brcap`; when the plan caps the range (free = 3 months), the chart comes from Alpha Vantage `TK.SAO` (avHist) instead; US via Finnhub quote/profile2/metric + Alpha Vantage daily/weekly history (cached a day, 25 calls/day limit). Line chart with touch tooltip and the user's preço médio line; indicators read defensively with `pickNum`.
- **Robô diário** (data repo `.github/workflows/mercado.yml` + `scripts/mercado.py`, GitHub Actions, free): runs 06:17 and 18:40 BRT and on every push of carteira.json; writes `mercado.json` (v 2) = `idx` histories for the Mercado index catalog (Yahoo real indices like ^BVSP/^GSPC/^IXIC/^DJI/GC=F, FX pairs, BTC/ETH-USD × BRL=X, IFIX.SA→XFIX11.SA fallback; CDI série 4389 rate + 12m from série 12; IPCA série 433 12m accumulated) shown by `idxOpen`/`idxRender` when an index card is tapped (when the robot symbol differs from the live proxy, the page uses the robot's last close and only the day % from the proxy) + Fundamentus indicators for all B3 stocks (`fund` {cols,d}) + `prov` {TK:[[datacom, valor/ação bruto, tipo, pagamento]]} from Fundamentus proventos.php (fii_proventos.php fallback) for every BR ticker ever bought, so sold stocks' announced proventos show up; the app feeds it to `provMD()` → `divApply()` (shared with brapi `loadDivs`; also fills `PVX` for per-share/qty of received ones), `DV.md`, merged/deduped in `mergeUp` + Yahoo 5y weekly/1y daily closes and dividend history for held + watched tickers (`hist`). The app reads it via the contents API (raw, ETag) in `loadMD` (cached `minha-carteira-v1-md`); `mdStk` builds the stock page instantly from it (live price from S.quotes/MKT.q), falling back to the API path only when a ticker isn't there yet. `fundOf(tk)` treats Fundamentus 0 as missing (except DY).
- **Assistente de IA** (rebuilt at the user's request; the old in-browser Gemini chat with key `S.keys.gm` is still deleted at startup): floating button `.asfab` (`data-as="open"`) opens the `#assist` sheet. `asAsk(q)` sends a system prompt `ASSYS` + `asCtx(q)` (compact plain-text summary built from the app: patrimônio, day change, holdings with nota/preço justo/indicators/news summary, proventos 12m + a receber, the Risco diagnosis parsed from `riskHtml`, macro via `idxVal`, robot `res.dia`/`res.cart`, garimpo + alerts, metas, alvos, and a DETALHE block for tickers named in the question) + the last 8 messages. Groq first (`S.keys.gq`, streaming SSE to api.groq.com, models from `ASGQ` filtered by /models, cached a day in `-asmg`; tries the next model on error), Gemini as fallback (`S.keys.gem`, `streamGenerateContent?alt=sse`, flash models discovered and cached in `-asmm`). Keys are entered in Ajustes (`#k-gq`, `#k-gem`) and stay only on the device. Conversation saved in `minha-carteira-v1-assist` (last 40), "Limpar conversa", suggestion chips `ASQ`, simple markdown `asMd`. The robot's AI (Research) is separate and uses the Actions secrets.
- **Research** (plan step 4): data repo `scripts/pesquisa.py`, called from mercado.py in full runs: Google Notícias RSS per BR ticker (carteira + lista; query `TICKER OR ("nome curto" (ações OR lucro ...))`, 30 days, 15 headlines) and, when the `GEMINI_KEY` Actions secret exists, Gemini (`gemini-2.5-flash` → fallbacks, JSON output) per ticker only when the headline set changed (`sig`), plus a portfolio report at most every 20 h. Output `MD.d.res` {at, ia, err, v:2, acoes:{tk:{news:[{t,s,d,l}], ai:{resumo, sentimento, confianca, eventos[{titulo,impacto,direcao,prazo,porque}], riscos, oportunidades}, aiAt, mod}}, cart:{ai:{titulo,macro,destaques,riscos,atencao},at}}. App: stock page tab `news` (`rsNews`), `rsMini` in Resumo, `rsCart` at the top of Mercado → Análise (collapsed by default; open/closed state kept in `RSCO`, `minha-carteira-v1-rsco`, so re-renders don't reopen it), status row in Ajustes. The key never goes to the app or the repo files.
- **Market Overview + balanços** (plan step 5): `mktOverview()` at the top of Mercado → Índices (AI daily text `MD.d.res.dia` {titulo,texto,carteira} written by the robot's `PROMPT_DIA` from the tape at most every 6 h, key-number tiles from `tapeItems()` that open `idxOpen`, your portfolio's day change, top gainers/losers among tape stocks). Juros EUA 10 anos (`^TNX`, IDX `tnx`, tape 'JUROS EUA 10A', shown as %). Quarterly results: data repo `scripts/cvm.py` reads CVM open data (FCA ticker→CNPJ, ITR + DFP DRE consolidated/individual; Q4 = year − 9 months) into `MD.d.cvm` {ts, q:{tk:[[ano,tri,receita,lucro]]}} refreshed every 4 days for carteira + lista; app `qHtml` (Indicadores tab, bar charts with tooltips), `qTtm` feeds the 'Lucro crescendo/caindo' rule in `stkAna`, and the AI prompt gets the last 5 quarters.
- **Balões**: `bal(text, inner)` makes a small tap-to-show explanation (`#balpop`, hides on any other tap or scroll). Used for unclear labels on Início and for the EUA line (shows US$ result, balloon has the reais conversion). Prefer balloons over more visible text. Every section added in the 'mini Aladdin' plan (Risco, análise, preço justo, resultados trimestrais, notícias/IA, oportunidades, relatório, resumo do mercado, classificação, comparar) has a ⓘ balloon in its title saying what it is and why it exists; keep that for new sections.
- **Toque nos gráficos**: a `.tipc` wrapper with `data-tip` JSON `{n:slots, pts:[{i,t,r:[[color,label,value,cls]]}]}` (built by `tipAttr`) gets a touch/drag tooltip (`tipShow`/`tipHide`, document pointer events; tap elsewhere hides). Used in Evolução and Proventos mês a mês; donut slices show their % in the center on tap.
- **Rendering**: `render()` calls `renderSummary`, `renderPositions`, `renderTrades`, `renderBanner`, `renderFx` — all rebuild HTML strings (escape with `esc()`); tabs switch via `showTab`. Form handling is in `syncForm`.
- **Live refresh `doRefresh()`**: every 5 min fetches USD-BRL and US quotes; BR quotes only every 15 min (`RF.lastBr`, brapi monthly limit; a manual refresh fetches all). Fetches USD-BRL from AwesomeAPI, US quotes from Finnhub (needs user key) and BR quotes from brapi.dev (needs user token, sequential with retry; skipped while B3 is closed once the closing price is cached, see `mktOpen`/`needQuote`). Uses `getJSON` with an 8s abort timeout.
- **Cabeçalho**: logo + 'Aporte' (bigger) on the left; on the right `#mktst` chips from `mktState()`/`renderMktSt()` (every minute): B3 (10h–18h Brasília, `bDay`) and EUA (NYSE 9h30–16h New York via Intl `nyNow()`, `usHol` US holidays), green dot = aberta, red = fechada, balloon says when it closes/opens in Brasília time.
- **Faixa de cotações** (`#tape`, below the header, full-bleed black, CSS marquee `.tptr` with the items twice, pauses on touch, static under reduced motion): `renderTape()` (called in `render()`, updates values in place when the item list is unchanged so the animation doesn't restart) from `MD.d.tape.it` [label, last, prev, cur] written by the robot (`tape()` in mercado.py: Yahoo range=1d for indices, dólar/euro, bitcoin, ouro, BR blue chips, US big techs, VT; scheduled every 15 min during the pregão with `TAPE=1`, which only refreshes `tape`), overridden by live S.quotes/MKT.q/S.fx, plus held tickers; stocks open `stkOpen`.
- **Um preço só** (user rule: every tab must show the same price): `livePx(tk)` returns the newest of S.quotes/MKT.q; `tapeMerge()` (start of `render()`) copies newer robot tape prices into S.quotes (held) or MKT.q; the stock page writes its fetched quote into MKT.q and `stkRender` shows `livePx` when newer; `idxVal` uses the tape for ibov/eur when newer; `renderTape` reads `livePx` and re-runs every 15 s. Cadence: dólar and everything American 5 min (`usRefresh()` inside `doRefresh` and right after the robot file loads: Finnhub quotes for the tape's US tickers, US watchlist and US index ETF cards → MKT.q / MKT.idx; slows down above 40 symbols to stay under 60/min), BR quotes and robot tape 15 min.
- **Commodities**: IDX entries with `src:'cmd'` (brent, wti, iron, silver, copper, soy, corn, coffee, natgas; Ouro `GLD` is now GC=F) read from the robot (`idx` histories, Yahoo futures; USX quotes divided by 100) and the tape (`tp` label via `tapeIdx`); added once to the user's índices (`idxCmdAdd`/`IDXMIG`, after the first cloud sync, flags `minha-carteira-v1-idxcmd` and `-idxselic` for Selic + CDI). Tape items are [label,last,prev,cur,'s'|'i',idxKey] (`tpStk`); 'i' items open `idxOpen`.
- **Anual** (range `yr` on stock and index pages): `annRets(hist,live)` = each calendar year's change from the previous year's last close (current year to today, first year partial), `annHtml` bars + acumulado + média por ano; stock pages load the 5y history for it (`rgEff()`).
- **Risco** (Carteira → Risco, `risk`/`#risktab`, plan step 1 of the user's 'mini Aladdin': Risco, Market Overview, Stock Analysis, Valuation, Research, Opportunities): `riskData(R)` (cached in `RKC`) builds weekly BRL returns from `MD.d.hist[tk].w` (VT × `idx.usd`), factor returns from `MD.d.idx` (`RFAC`: ibov, usd, SPY, brent, iron, GLD), per-asset vol/betas/2-factor (ibov+usd) regression/max drawdown, the current-weights portfolio backtest (vol, max drawdown with recovery, worst week, 4-week VaR 95%, beta), pairwise correlations, sectors (robot `sect` from Fundamentus detalhes.php, grouped into B3 sectors by `RKSG`), dollar share and effective N. `riskHtml` writes the automatic diagnosis (ok/atenção/alerta), preset scenarios (`rkImpact`), the simulator (`#rk-f`/`#rk-s`, `RSIM`), the backtest chart, composition, per-asset table and correlation matrix. RF counts as CDI with zero volatility.
- **Análise da ação** (plan step 2; stock page tabs `data-stv` Resumo/Preço justo/Indicadores/Notícias (user wants all UI words in Portuguese), `STV` saved in `minha-carteira-v1-stv`): `stkAna(tk,d)` normalizes indicators (`anNums`: Fundamentus for BR, Finnhub `d.k` for US), compares with the sector median (`anPeers`: robot `peers` {setorId:[tickers]} from Fundamentus resultado.php?setor=, `sect[tk]=[setor,subsetor,id]`, peers with liq2m ≥ 200 mil) and rules (ROE, ROIC, margem, dívida/PL, liquidez corrente, crescimento 5a, P/L e P/VP vs setor, DY, distância da máxima, liquidez, volatilidade; banks skip debt/ROIC/margin) → pontos positivos/atenção/vale saber, chips Qualidade/Preço/Dividendos/Risco and a 0–10 score; `anFit` = the stock inside the portfolio (peso, setor, correlação with the rest via `riskData`). `anVal` = Graham, Bazin (preço-teto), P/L do setor and a simple DCF (LPA growth `g` 5 years then 3%, discount Selic+1 min 12%), median = preço justo, margem de segurança; assumptions editable per ticker (`VALP`, `data-valp`). ETFs get a short note instead.
- **Oportunidades** (plan step 3; top of Mercado → Análise, `oppHtml`, views `OPV` lst/car/gar saved in `minha-carteira-v1-opv`): `opData()` (cached `OPC`, 15 min) runs `opEval` (= `stkAna` + `anValCalc`, the Valuation math shared with `anVal`) on the watchlist, the BR holdings and a garimpo of every stock with liq2m ≥ R$ 2 mi (nota ≥ 6, qualidade não baixa, preço justo ≥ 20% acima, DY ≤ 20%, one ticker per company, top 12 by `rank`). `opSnap` stores a daily snapshot [date, nota, justo, preço] per ticker in `minha-carteira-v1-opp`; `opAlerts` compares with the snapshot ≥ 6 days old (nota ±1, preço ±10%) plus abaixo/acima do preço justo, queda ≥ 25% da máxima, DY. The alert count shows as a red badge on the Análise sub-tab (`.mkb`); the star (`data-wtog`) adds a garimpo stock to the watchlist.
- **Pregão**: `b3Hol(ymd)` knows B3 holidays (fixed dates + Carnaval/Sexta-feira Santa/Corpus Christi from Easter); `bDay`, `mktOpen`, `lastClose` and `dayLbl` skip them.
- **Dividendos dos EUA**: `loadDivsUS()` (every 12h, key `S.keys.av`) calls Alpha Vantage `function=DIVIDENDS` per US ticker; data-com = ex-date − 1 day; value = qty × amount minus 30% US withholding (`bruto`/`irExt` in USD). Future payments go to `DU.up` (cached `minha-carteira-v1-divus`, `val` in BRL at today's dollar, `us:1`); paid ones on/after `S.divFrom` are auto-added as `div` trades (dedupe ±7 days). `mergeUp()` joins `DV.br` (brapi) and `DU.up` into `DV.up`.
- **Taxas**: BR buy/sell trades may carry `taxa` (fees from the Nubank note, R$, split across the note's trades by value). `ePx(t)` gives the effective price (buy: price + taxa/qty; sell: price − taxa/qty). The user wants fees kept OUT of the preço médio (matches Nubank): compute() keeps cost basis/realized at the plain price, uses ePx only for cash/contrib/flows, and reports `tot.fees` as its own line (subtracted from `tot.gain`). ePx is used fully in irData (gain only; the R$ 20 mil limit uses gross sales) and bensEm (Receita rules), and for cash in evoData, benchSeg, cdiBench and the Extrato totals.
- **Renda fixa**: trades with `side:'rf'` (aplicação: `price` = valor aplicado, `pct` = % do CDI, `isento`, `venc`) and `side:'rfout'` (resgate, `ref` = aplicação id, `price` = valor recebido), `market:'RF'`. `rfCalc()` compounds the BCB SGS série 12 daily CDI (`loadCDI`, cached in `minha-carteira-v1-cdi`) from the aplicação date up to (not including) today/resgate, then applies IOF (<30 dias) and IR regressivo on (rendimento − IOF).
- **Cloud sync**: `ghSync()` reads/writes `carteira.json` in the private repo `THIAGOATAIDE2003/minha-carteira-dados` via the GitHub contents API with the user's fine-grained token (`S.keys.gh`); local edits queue in `S.pend` (add/del ops) and are replayed on the latest remote on conflict.
- **Evolução** (Investidor10 style): `renderEvo` draws stacked bars per month: Valor aplicado (`--ev1`, cost of holdings at that month's dollar) + Ganho de capital (`--ev2`, value − cost; negative drawn below zero), y axis in a separate SVG, touch tooltip, table in a collapsed details. Filter sheet (`#evsheet`, `EVF` {p:'all'|'12'|'24'|'60'|'120', t:'all'|'BR'|'US'|'RF'}, saved in `minha-carteira-v1-evof`). `evoData()` rows carry `seg` {BR,US,RF:{v,c}}. `evoData()` replays trades up to each month end; prices come from brapi daily history (`loadHist`, cached in `minha-carteira-v1-hist`) or `fechamentos` in the cloud file (month closes; the app records the current month's auto quotes as `px` ops, once a day), falling back to average cost (marked *).
- **Aporte**: `S.alvos` `{classes:{BR,US,RF}, br:{ticker:%}}` synced as a `cfg` op (`applyCfg`); `splitNeed` sends new money to what is furthest below target, never sells.
- **Mercado**: `loadBench` caches BOVA11/IVVB11 daily closes (`minha-carteira-v1-bench`); `benchSeg(mk,etf)` replays each segment's buys/sells into the ETF on the same dates and compares gains (portfolio side includes dividends).
- **Metas**: `S.metas` `{pat:{valor,data}, renda:{valor}}` synced as a `cfg` op; `metasHtml` (Início) shows progress, the monthly contribution needed at the CDI rate, and time to goal at the recent contribution pace.
- **Imposto**: `irData()` replays BR buys/sells (average cost) per month: ações isentas até R$ 20 mil de vendas no mês, senão 15%; FIIs (`FIIS` list) 20%; prejuízo carried per category. `bensEm(date)` gives Bens e Direitos cost at 31/12; proventos split by `tipo` (JCP/Dividendo) and exterior (`bruto`, `irExt`).

Keep user data and API keys out of the repo; the app must keep working offline from `localStorage` when network calls fail.

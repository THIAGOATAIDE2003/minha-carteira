Referência por funcionalidade (histórico de decisões e nomes de funções). Movida do CLAUDE.md para ele ficar curto. Consulte só a parte da área que for mexer (use `grep -n` pelo nome).

## Architecture

The app is `index.html` (markup) + `style.css` + `js/*.js` (~3,850 lines in 32 files, ~550 KB; see the file list and load order in CLAUDE.md). `manifest.webmanifest`, `icon.svg` and `sw.js` (service worker, cache-first since 1.41.0: the whole version is precached atomically at install with `cache:'reload'` and served from the cache, so the app opens instantly and offline; requests with `_v=` or `no-store` go to the network; never touches API calls; see 'Velocidade') make it installable. Code is written in dense ES5 style (`var`, `function`, no modules) — keep that style when editing.

Key pieces inside the script:

- **State `S`** (persisted to `localStorage` key `minha-carteira-v1` via `save()`): `trades`, `cambio`, `quotes` (auto price cache), `fx`, `keys` (Finnhub, brapi and GitHub tokens), `pend` (cloud ops queue), `mclose`, `divFrom`. A separate key `minha-carteira-v1-fxh` caches the USD-BRL daily series (refetched after 6h).
- **Market data `MK`**: `ingestFx` loads the FX series; `getQuote(tk)` reads `S.quotes`; `fxOn(date)`/`fxToday()` resolve exchange rates.
- **`compute()`**: the core calculation. Sorts trades by date, builds per-ticker positions (qty, cost basis, realized P/L, dividends via `side==='div'`), converts US trades with each trade's `fx`, builds cash-flow list for `xirr()`.
- **Tabs**: bottom nav `resumo` (Início), `ativos` (Carteira, sub-views `pos`/`evo`/`apo`/`perf`/`ext` (Extrato, hashes `#extrato`/`#lancamentos`) via `data-sub2`/`CARV`, hashes `#evolucao`/`#aporte`/`#desempenho`/`#risco`; `perf` = `renderPerf`/`perfHtml`: carteira contra o mercado e o CDI), `proventos` (Investidor10 style, `renderDivPanel`/`pvRedraw`: `pvItems()` unifies received `div` trades and announced `DV.up` with status rec/up/def; swipe cards `#pcards`/`PCI` (total, 12 meses, este mês, provisionados, média mensal with metas.renda ring); `pvEvo` stacked bars recebidos + a receber (up to 6 months ahead) with sheet `#pvsheet` (período, mensal/anual, tipo, ativo); `pvAtivos` donut + bars (selects `data-pvs`); `pvList` 'Meus proventos' with period sheet `#pvlsheet` (incl. month picker), filter sheet `#pvfsheet` and details table `#pvdsheet`; settings in `PV`, saved in `minha-carteira-v1-pv`; open sheet kept in `PVS` across re-renders; then `divPorAtivo`), `mercado` (`renderMkt`/`loadMkt`, sub-tabs `#mkseg` `data-mkv` → `MKV` 'min'/'idx'/'ana' saved in `minha-carteira-v1-mkv`: 'min' = `mineHtml` (holdings with price, day %, P/L·P/VP·DY) + watchlist; 'ana' = `anaHtml` (ranking presets `SCRS`/`SCR` over `MD.d.fund`, liquidez ≥ R$ 1 mi, and 'Comparar duas ações' form `#cmpf` → `CMP`); 'idx' = índices; search bar `#mk-q` (`mkSearch`: catalog indices + any ticker to open/acompanhar) and user-chosen índices from the `IDX` catalog (brapi ^BVSP/XFIX11/SMAL11/DIVO11, Finnhub SPY/QQQ/DIA/ACWI/EEM/GLD, AwesomeAPI moedas/cripto, BCB Selic meta série 432, CDI and IPCA 12m; robot `idx.selic` history, future-dated entries dropped), selection `S.idxSel` synced as cfg op 'idx', "Editar" shows ✕ on cards; and the watchlist `S.watch`, synced as cfg op 'watch', cached `minha-carteira-v1-mkt`), `mais` (sub-views `cambio`/`imposto`/`ajustes` via `data-sub` and `MAISV`); `showTab` accepts the old hashes.
- **Temas**: `atual` = "Azul" (default, the dark navy palette on bare :root, no data-theme; unchanged), `branco` (matte off-white #e8e9eb, not pure white), and `preto` = the lighter Google-like dark gray (#202124/#303134), NOT pure black (user asked to replace the old strong black with it) via `data-theme` on <html>, chosen in Ajustes (`#temas`, `setTema`), stored per device in `minha-carteira-v1-tema` and applied by `tema.js` before paint. No automatic dark mode.
- **Gráficos**: SVG helpers `spark(rows)` (hero, from `evoData()`), `distHtml(R)` (Distribuição on Início: swipeable pages `#dcar`/`DCI` — Por tipo, Todos os ativos, Ações, ETFs Intern., Renda fixa when present — big donuts; tapping a slice `.dsl` shows `#dtip` with name, % and R$ and dims the others), `vsBars` (vs mercado/CDI); waterfall bars in "De onde vem"; Evolução is an area chart plus monthly rendimento bars. Long explanatory notes carry class `note exp` and are wrapped by `foldNotes()` (MutationObserver) into a collapsed "Entenda" `details.info`.
- **Início vs Desempenho** (user rule: never mix câmbio/vendas into the Início numbers): hero is a swipeable card row (`#hcards`, scroll-snap, dots `HCI`, like Investidor10): order Patrimônio total (% vs valor investido at today's dollar), then Variação de hoje / Último pregão, then Valorização (user's order) (price only, VT × today's dollar for both closes, split Brasil/VT). Valorização = `valoriz(R)` (price variation of holdings with VT at today's dollar + RF rendimento + proventos received; % over cost at today's dollar). Início now holds only the hero cards, then Distribuição, then Metas (user wants it uncluttered); "Carteira hoje" (`hojeHtml`) and "Quanto você investiu" (`investHtml`) moved to the end of Desempenho. The full breakdown (preço, dólar, vendas, proventos, taxas, lucro total, simples, XIRR) lives at the top of `perfHtml` (Carteira → Desempenho); its preço line uses `valoriz().pv` and dólar is the remainder so the sum still equals `tot.gain`.
- **Ativos (Carteira → Ativos)**: `atvTable(R)` = Investidor10-style table (logo from icons.brapi.dev / financialmodelingprep image-stock with initials fallback, qty, Total % and Dia % pills via `vpill` → tap shows the R$ value in a balloon, tap the ticker cell (sticky first column) opens `stkOpen`; the table scrolls sideways (`.atsc`) with extra columns Total R$, Preço médio, Preço atual, Valor); filter `ATF` all/BR/US, sort `ASRT` by header tap. Price-only basis (VT × today's dollar). Renda fixa and Encerradas stay as groups below.
- **Página da ação** (`#stk` sheet, `stkOpen(tk)` from any `[data-stk]`): BR via brapi: main quote with the largest range the plan allows (falls back 5y→1y→6mo→3mo→1mo→none), then separate optional calls for modules and dividends=true; what the plan refuses is remembered in `minha-carteira-v1-brcap`; when the plan caps the range (free = 3 months), the chart comes from Alpha Vantage `TK.SAO` (avHist) instead; US via Finnhub quote/profile2/metric + Alpha Vantage daily/weekly history (cached a day, 25 calls/day limit). Line chart with touch tooltip and the user's preço médio line; indicators read defensively with `pickNum`.
- **Robô diário** (data repo `.github/workflows/mercado.yml` + `scripts/mercado.py`, GitHub Actions, free): runs 06:17 and 18:40 BRT and on every push of carteira.json; writes `mercado.json` (v 2) = `idx` histories for the Mercado index catalog (Yahoo real indices like ^BVSP/^GSPC/^IXIC/^DJI/GC=F, FX pairs, BTC/ETH-USD × BRL=X, IFIX.SA→XFIX11.SA fallback; CDI série 4389 rate + 12m from série 12; IPCA série 433 12m accumulated) shown by `idxOpen`/`idxRender` when an index card is tapped (when the robot symbol differs from the live proxy, the page uses the robot's last close and only the day % from the proxy) + Fundamentus indicators for all B3 stocks (`fund` {cols,d}) + `prov` {TK:[[datacom, valor/ação bruto, tipo, pagamento]]} from Fundamentus proventos.php (fii_proventos.php fallback) for every BR ticker ever bought, so sold stocks' announced proventos show up; the app feeds it to `provMD()` → `divApply()` (shared with brapi `loadDivs`; also fills `PVX` for per-share/qty of received ones), `DV.md`, merged/deduped in `mergeUp` + Yahoo 5y weekly/1y daily closes and dividend history for held + watched tickers (`hist`). The app reads it via the contents API (raw, ETag) in `loadMD` (cached `minha-carteira-v1-md`); `mdStk` builds the stock page instantly from it (live price from S.quotes/MKT.q), falling back to the API path only when a ticker isn't there yet. `fundOf(tk)` treats Fundamentus 0 as missing (except DY).
- **Assistente de IA** (rebuilt at the user's request; the old in-browser Gemini chat with key `S.keys.gm` is still deleted at startup): floating button `.asfab` (`data-as="open"`) opens the `#assist` sheet. `asAsk(q)` sends a system prompt `ASSYS` + `asCtx(q)` (compact plain-text summary built from the app: patrimônio, day change, holdings with nota/preço justo/indicators/news summary, proventos 12m + a receber, the Risco diagnosis parsed from `riskHtml`, macro via `idxVal`, robot `res.dia`/`res.cart`, garimpo + alerts, metas, alvos, and a DETALHE block for tickers named in the question) + the last 8 messages. Analyst mode: `asFind(q)` finds up to 3 companies by code or by name (`asIdx` index built from robot `cvm.nomes` (FCA razão social for every ticker), `hist[tk].name`, `res.acoes[tk].nome` and the nickname table `ASAL`, picking the most liquid ticker; `ASSTOP` blocks generic words, and phrases like 'vale a pena' are removed before matching), and `asEmp(tk)` adds an `=== EMPRESA` block with every number tagged with its source and date: price, Fundamentus indicators, sector median from `anPeers`, CVM quarters (`cvmQ`/`qTtm`), the app's rule-based analysis (`stkAna` pos/neg/inf) and preço justo with its assumptions (`anValCalc`), `anFit`, robot news summary + headlines, and a `NÃO DISPONÍVEL NO APP` line listing what is missing. The block also carries: sector, price change 1m–5y and 12m total return + proventos per share 12m vs previous 12m (`asPxHist`, robot `hist`), operating multiples (P/EBIT, EV/EBIT, margem EBIT, PSR), balance sheet from robot `bal` (Fundamentus detalhes.php: dívida bruta/líquida, caixa, patrimônio, receita/EBIT/lucro 12m, scaled with `pl_r`; also fills `fundOf().divpl` when the resultado.php column is missing), peers deduped one ticker per company and without holdings of the same company (`ANHOLD`), with count and confidence, sector commodity (`asCmd`: iron/brent), quarters with receita and lucro changes separated, each preço justo method with what it assumes, and a LUCRO DISTORCIDO warning when margem líquida < 30% of margem EBIT (same rule adds a 'Vale saber' in `stkAna` and a caution in `anVal`). When companies are named, holdings' news and the market/report/garimpo lines are dropped to fit the free Groq token limit. `ASSYS` includes an indicator-reading guide. `ASSYS` requires answers to cite sources, never invent data, and use **Os números** / **Minha leitura** / **O que falta saber** for company analyses. Groq first (`S.keys.gq`, streaming SSE to api.groq.com, models from `ASGQ` filtered by /models, cached a day in `-asmg2`; on HTTP 413 (request above the free-tier token limit) it retries the same model with the compact context `asMsgs(q,true)` (`ASCMP`: holdings without analysis, risk only when asked, fewer quarters/headlines, 2 short history messages), then tries the next model; llama-4-scout has the largest free limit), Gemini as fallback (`S.keys.gem`, `streamGenerateContent?alt=sse`, flash models discovered and cached in `-asmm`). Keys are entered in Ajustes (`#k-gq`, `#k-gem`) and stay only on the device. `S.asia` ('gem' default since 1.42.1 — set in `nucleo.js` when unset | 'groq', select `#k-asia` in Ajustes) picks which provider answers first; the other one is the fallback (`provs`/`run` in `asAsk`). Gemini gets the full context (no compact mode) and `maxOutputTokens` 6000 because its thinking tokens count. "Testar a IA" button in Ajustes → Assistente (`js/assistente-teste.js`, `asTeste`): sends a minimal question to Groq and the top 3 Gemini models with the user's keys, shows time/error of each in `#as-teste`, reorders the Gemini model cache (`-asmm2`) with the working ones first, and flips `S.asia` to whichever provider works if the chosen one does not. Cálculos do app no contexto (1.45.0, `js/assistente-calculos.js`): `asCenario(q)` (segmento `cen` de `asCtx`) faz a conta de cenário (dólar/bolsa BR/bolsa EUA; 'cenário adverso' sem números = dólar −15% e Brasil −20%, avisado) com `compute().held` e devolve patrimônio final, Δ R$, Δ%, por ativo, efeito separado, lucro total e suposições (a IA só interpreta); `asAporte(q)` (segmento `apo`) chama `splitNeed` com o alvo salvo (`S.alvos.classes`) ou, se não houver, o do perfil (`pfAlvo`), informando a origem, e diz que é divisão matemática, não recomendação; `asXt` liga os dois blocos nas rotas (`asRota`, `asMsgsE`, `asMsgsMini`). Setor: `asTipo/asTipoTxt/asFin/asMultFin/asBalFin/asFaltaTipo` separam banco, seguradora e serviços financeiros (indicadores que não se aplicam não entram em 'NÃO DISPONÍVEL'; concorrentes de banco/seguradora só P/L, P/VP, DY, ROE); `politica.js` tem juros/PIB próprios para seguradora e B3. `asPayout` descreve o payout como aproximação (DY×P/L e proventos Yahoo ÷ LPA implícito), sem afirmar reservas; `asDist(F)` é o critério único do LUCRO DISTORCIDO (também no modo compacto de `ATIVOS`, que agora mantém o preço justo). Fontes: `asConc` avisa diferença de 3%–25% entre lucro Fundamentus e soma CVM com período de cada um; 'Eventos' do resumo de notícias são da IA do robô, não manchetes. `compute()`, `valoriz()`, `xirr()`, `splitNeed` e `ASSYS` intactos. Métricas da carteira no contexto (1.44.8): `asCtx` base now sends three labeled lines instead of one — PATRIMÔNIO TOTAL (= ativos + caixa; custo das posições abertas; ativos − custo = preço + câmbio), VALORIZAÇÃO (only price + proventos, no câmbio/vendas, 'NÃO é o lucro nem o prejuízo total', base at today's dollar) and LUCRO TOTAL (= ativos − custo + vendas realizadas + proventos − taxas; XIRR). Only labels/reconciliation: `compute()`, `valoriz()`, `xirr()` and `ASSYS` untouched. Tests: 3 checks in teste.js (identities + hand-made scenario). Desempenho (1.44.7): Gemini 429 only waits when retryDelay ≤5 s and once per question (not per model), 2 models max, Gemini history = last 6 msgs × 700 chars (memory `asmCtxT` unaffected), `asRota` adds risco for 'análise/diagnóstico … carteira', `dados_empresa` tool returns a short 'já enviado' for companies already in the question. `aspNew/aspB/aspFb/aspSave` log each question (1º texto, total, chamadas, caracteres, modelo, trocas) to `-asperf` (last 30); Ajustes → 'Ver desempenho das respostas' (`asPerf`). Margem por fonte (1.44.6): `asConc` also emits 'MARGEM LÍQUIDA POR FONTE' (margin from each lucro ÷ same receita, says which lucro matches the published margem; `asConf` already flags DIVERGE vs the Fundamentus lucro) + rule 14 (no 'consumido por juros/impostos' without composition). Source reconciliation (1.44.5): `asConc` adds a 'CONCILIAÇÃO DE FONTES' line when the Fundamentus 12-month lucro (balance page) and the CVM 4-quarter sum differ by more than 25% (both values, period, 'causa desconhecida'); `asCmd(sec,px)` appends a pre-checked stock-vs-commodity 12-month comparison (signs and direction computed by the app); `ASSYS` rules 11–13 (divergent sources, comparisons, no 'saudável' from margin+debt) and the Minha leitura tags (dado confirmado / fontes divergem / hipótese). Per-question context (1.44.4): when the question names a company (`asFind`), Groq starts at the company level (`asMsgsE` = full `ASSYS` + only that company's `asEmp` block + a lean portfolio summary + memories) instead of the full portfolio context (`ASQ1` holds the chat question while it runs); after a 429 a provider is paused for 60 s (`ASCD`) so the next question goes straight to the other one; the 413 text says the request was too big even reduced. Groq tiers (1.44.3): on HTTP 413 `asGroq` goes full → compact (`asMsgs(q,true)`) → mini (`asMsgs(q,2)` = `asMsgsMini`: `ASMINI` short prompt + only the named company block or base+metas, 9000 chars) before trying the next model; HTTP 429 messages now carry the API's own reason, and a Gemini 429 with `retryDelay` ≤ 20 s waits and retries once. Number check (1.44.2): `asConf(F,B,L)` in `asEmp` recomputes margem EBIT (EBIT÷receita), margem líquida (lucro÷receita), P/L (P/VP×patrimônio÷lucro) and dívida líquida/EBITDA (EBITDA = EBIT×EV/EBIT÷EV/EBITDA) from the raw balance numbers and emits a 'CONFERÊNCIA DOS NÚMEROS' line marking each as confere/DIVERGE; cyclical sectors (Materiais, Petróleo, Papel, Agro…) get an ATENÇÃO note on the preço justo line; `ASSYS` rules 9–10. Safer reading (1.44.1): `asEmp` states the direction of the preço justo explicitly ('o preço justo está X% ABAIXO/ACIMA do preço atual (o preço atual é N vezes…)'), classifies dívida líquida/EBIT (caixa líquido/baixa <2×/moderada <3,5×/alta) and, when `dist` (LUCRO DISTORCIDO), puts the warning RIGHT AFTER the header with a hard rule (no cara/barata by P/L, ROE, LPA or preço justo; no cause) and tags the preço justo line NÃO CONFIÁVEL; `ASSYS` rules 6–8 (never invert direction, obey NÃO CONFIÁVEL, strong conclusions need ≥2 agreeing numbers else 'sinal misto'). Assistant memory + retry (1.44.0, `js/assistente-memoria.js`): `asmNota(q)` (called at the start of `asAsk`) saves non-question messages that match `ASMRE` (lembre/anote/guarde/minha tese/minha regra/meu objetivo…) into `ASM` (`minha-carteira-v1-asmem`, max 40, with tickers from `asFind`); `asmCtxT(q)` appends the relevant ones (company named + general; all when the question talks about tese/decisão) to the context in both `asMsgs` and `asMsgsT`; list with delete (`data-asmdel`) under the history view (`asmHtml`). `asSysAtual()` rebuilds `ASSYS` from `ASSYS0` with the CURRENT holdings instead of the old fixed 'ações da B3, VT e renda fixa' text, plus the MEMÓRIAS rule. Answers that failed (`a.e`) or were cut mid-stream (`a.cut`) show 'Tentar de novo' (`data-as=retry`, `asRetry`). Gemini with tools (1.43.0, `js/assistente-ferramentas.js`): in the chat (`asAsk` only; reports/plano/bc keep the full context) the Gemini provider is `asGemT` — it gets `asMsgsT` = `ASSYS` + `ASTH` + a lean context (`asCtx(q,{base,ativos,metas})` with `ASCMP` on) + the `asEmp` block of any company named in the question, and function-calling tools `ASTD` (dados_empresa, carteira_detalhada, proventos, risco, oportunidades, mercado_e_economia) that run locally via `asToolRun` (`asCtx(q, only)` returns only the named blocks; sections are tracked with `seg()` inside `asCtx`). Thinking is capped (`asThink`: gemini-3 `thinkingLevel:'low'`, 2.5 `thinkingBudget:1024`; retried without it on HTTP 400) so chat answers start fast. Gemini flash models are ordered with 2.5 first (`asGemModels`, cache `-asmm2`; the newer 3.x ones can hang) and the chat tries at most 2; each request has 25 s to its first data (`asGemT`: own AbortController; on timeout it tries the next model, then the provider fails so Groq takes over; global timeout 100 s); `AS.st` holds the current stage and is appended to the 'Demorou demais' message. `asRota(q)` picks by keywords which blocks to send up front (proventos, risco, oportunidades, mercado; `det` = full per-asset analysis) so most questions cost ONE Gemini request (free-tier limits are per request and per model); tools are only a safety valve, max 2 rounds, and 3 models are tried (a 429 on one model moves to the next). Up to 2 tool rounds, the model's used tools show in the answer label ('consultou …'); on HTTP 400 it falls back to the old `asGem` with the full context; Groq stays the fallback provider with the full context. Several chats (1.42.0): `ASC` = saved conversations `{id,t,at,m}` in `minha-carteira-v1-aschats` (max 30, newest first; the old single chat in `-assist` is migrated once); `AS.m` is always the open chat, `AS.id` its id, an empty chat is not stored until its first message (`asSave`). Header buttons: `+` `asNovo()`, list icon toggles `AS.hist` (history list in `asRender`: `data-asopen` opens, `data-asdel` deletes), speaker `asvToggle()`; switching/deleting is blocked while `AS.busy`. Voice (`js/assistente-voz.js`, free, uses the browser's own SpeechRecognition/speechSynthesis, pt-BR, no key, no CSP change): mic button `#as-mic` dictates and sends when the phrase ends (`asvMic`; hidden if the browser has no SpeechRecognition), answers are read aloud when the question was spoken or when the speaker toggle `#as-v` is on (`asvFim`, called at the end of `asAsk`), plus an "Ouvir" button under each answer (`asvOuvir`); long text is spoken in sentence blocks. "Copiar" under each answer (`data-asc`, `asCopy`: plain text without `**`, clipboard API with execCommand fallback), suggestion chips `ASQ`, simple markdown `asMd`. The robot's AI (Research) is separate and uses the Actions secrets.
- **Perfil do investidor**: `S.perfil` {obj renda/cresc/ambos, prazo 5/10/20/30, reac vende/espera/compra, queda 10/20/30/40 (% the user accepts), ext %, rf %, res sim/parcial/nao, ap (monthly contribution), at}, synced as cfg op 'perfil' (carteira.json `perfil`). Questions in `PFQ`; Ajustes box `#perfbox` (`pfBox`, rendered from `render()`), questionnaire sheet `#pfsheet` (`pfOpen`/`pfSheet`, draft `PFD`, `data-pf`). `pfTipo` = Conservador/Moderado/Arrojado from prazo + reação + queda; `pfAlvo` = Brasil/exterior/RF split. Used by: Risco diagnosis (`pfRisco` items first: worst drawdown vs accepted drop, exterior vs wanted, reserva, short prazo with high vol; asks to fill it when missing), the assistant context (`pfCtx`) and prompt, garimpo `rank` (renda → DY bonus, cresc → 5y growth bonus), Aporte ('Pelo seu perfil' row with `#al-pf` filling the targets, and `APV` prefilled with the monthly amount).
- **Research** (plan step 4): data repo `scripts/pesquisa.py`, called from mercado.py in full runs: Google Notícias RSS per BR ticker (carteira + lista; query `TICKER OR ("nome curto" (ações OR lucro ...))`, 30 days, 15 headlines) and, when the `GEMINI_KEY` Actions secret exists, Gemini (`gemini-2.5-flash` → fallbacks, JSON output) per ticker only when the headline set changed (`sig`), plus a portfolio report at most every 20 h. Output `MD.d.res` {at, ia, err, v:2, acoes:{tk:{news:[{t,s,d,l}], ai:{resumo, sentimento, confianca, eventos[{titulo,impacto,direcao,prazo,porque}], riscos, oportunidades}, aiAt, mod}}, cart:{ai:{titulo,macro,destaques,riscos,atencao},at}}. App: stock page tab `news` (`rsNews`), `rsMini` in Resumo, `rsCart` at the top of Mercado → Análise (collapsed by default; open/closed state kept in `RSCO`, `minha-carteira-v1-rsco`, so re-renders don't reopen it), status row in Ajustes. The key never goes to the app or the repo files.
- **Market Overview + balanços** (plan step 5): `mktOverview()` at the top of Mercado → Índices (AI daily text `MD.d.res.dia` {titulo,texto,carteira} written by the robot's `PROMPT_DIA` from the tape at most every 6 h, key-number tiles from `tapeItems()` that open `idxOpen`, your portfolio's day change, top gainers/losers among tape stocks).
